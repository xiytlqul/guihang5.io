玩法说明
  • 入学前：① 三选天赋 → ② 3+1+2 选科 → ③ 模拟高考（六科十八题，300~750 分）→ ④ 出分后按物理/历史大类填报志愿；分数过低会落榜。
  • 四学年共八学期，每学期四个月；寒暑假各两个月，共 48 个月，每月一个事件、四个选项。每月结算后可「再做一件」额外推进事件（心情 -5）。
  • 属性：体质过低会生病甚至猝死；智力不高又不用功就可能挂科；道德过低会惹祸甚至犯罪；心情低于 0 会彻底崩溃、无法继续。
  • 科目分专业课与选修课，期末按智力与平时投入结算成绩，挂科可补考，补考不过计入挂科记录。
  • 每年体测、四六级、竞赛、奖学金等事件按属性结算，荣誉会写进毕业档案。
  • 毕业时按学业、体质、道德、心情社交、荣誉与惩罚综合评定 S / A / B / C / D。
  • 键盘 A/B/C/D 或 1-4 可快速选择选项，Enter 进入下个月。
